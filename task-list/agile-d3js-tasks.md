# マインドマップ Web ツール開発アジャイルタスクリスト（未完了タスクのみ）

---

## 新たな学び・運用ルール（2025-07-04 更新）

- タスクリストの進捗管理は「完了済みタスクは従来リスト（native-d3js-tasks.md）」「未完了タスクはアジャイル形式（agile-d3js-tasks.md）」で分離管理する。
- アジャイルタスクリストは「スプリント」「ユーザーストーリー」「タスク」単位で記述し、進捗や要望に応じて柔軟に分割・再編成する。
- タスクの粒度は「ユーザー価値」「画面上の変化」「技術的なまとまり」を意識して設計する。
- スプリントごとに「ユーザーストーリー」を明記し、開発の目的・価値を常に意識する。
- 完了済みタスクの管理・記録は従来リストで一元化し、アジャイルリストは常に「未完了タスクのみ」を最新状態に保つ。
